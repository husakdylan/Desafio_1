# 📖 La Bitácora del Pasajero

¡Bienvenido/a a **La Bitácora del Pasajero**! Un sitio web desarrollado en HTML5 semántico puro, diseñado para guiar a lectores por las extensas bibliografías de grandes autores literarios mediante rutas de lectura recomendadas, análisis y sinopsis.

---

## 🎓 Contexto del Proyecto

Este proyecto fue desarrollado como parte de las entregas y prácticas del programa en **Plataforma 5**. 

El objetivo del desafío es aplicar los conceptos fundamentales de desarrollo web frontend y estructuración de contenido, priorizando una maquetación limpia, accesible y estándar antes de la incorporación de estilos y lógica avanzada.

---

## 🚀 Sobre el Proyecto

Muchas veces, abordar la obra de un autor legendario puede ser abrumador. Este sitio actúa como un cuaderno de viaje digital para saber exactamente por dónde empezar a leer a autores como Stephen King, Agatha Christie y J.K. Rowling.

### 🛠️ Puntos Clave Evaluados
* **Maquetación 100% Semántica:** Construcción estricta utilizando etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<form>`, `<footer>`).
* **Accesibilidad (a11y) y SEO:**
  * Jerarquía clara de encabezados (`<h1>`, `<h2>`, `<h3>`).
  * Atributos `alt` descriptivos en todas las imágenes.
* **Formatos de Texto y Listas:** Manejo correcto de listas ordenadas (`<ol>`), desordenadas (`<ul>`), negritas, itálicas, subrayados y saltos de línea.
* **Interacción y Formularios:** Estructura completa de formulario con etiquetas asociadas (`<label>`), campos obligatorios (`required`) y distintos tipos de `inputs`.
* **Navegación e Integración:** Enlaces internos entre las distintas páginas del sitio y enlaces externos hacia la plataforma **Goodreads**.
* **Comentarios e Inspector:** Incorporación de guiños y comentarios HTML pensados para la revisión en la consola/inspector de elementos.
